# Contributing to Kid Buddy Bharat

Thanks for your interest in improving Kid Buddy Bharat (बाल रक्षक).

## How to contribute

1. Fork the repository and create a branch from `main` (for example `feature/geofence-alerts`).
2. Keep changes focused: one feature or fix per pull request.
3. For the iOS app, build and run in Xcode and test on a simulator or device before opening a PR.
4. For the web command center, run `node server.js` and check the page in a browser.
5. Open a pull request describing what changed and why, with screenshots for UI changes.

## Reporting bugs and ideas

Open an issue with steps to reproduce, the expected result, and your device or browser.

## Safety note

This project deals with children's location data. Never commit real location data, phone numbers, API keys or personal information.
